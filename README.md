# ☀️ Lumen Solar

Landing page responsiva desenvolvida para uma empresa fictícia de serviços de energia solar.

O projeto foi criado com foco em conversão de clientes e conta com formulário de contato, simulador de economia, FAQ interativo, integração com WhatsApp e animações.
