## 🎯 O Desafio / Objetivo
O objetivo deste projeto foi desenvolver uma Landing Page voltada para Geração de Leads / Agendamentos via WhatsApp.

O objetivo principal era criar uma interface que não apenas fosse esteticamente premium, mas que utilizasse arquitetura persuasiva (Copywriting) e hierarquia visual para guiar o usuário diretamente para a ação principal, reduzindo o custo por aquisição (CPA) de um cliente fictício.
